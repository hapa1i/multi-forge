## One disposable Claude case

Build the manifest's explicitly tagged development image with Claude 2.1.245 and Codex 0.149.1. Use the exact container
name `forge-native-purge-20261020`; refuse if that name already exists. Create `/probe/workspace` and a separate
`/probe/home` inside it. No host home, credentials directory or repository directory is mounted. The fixed script
arguments and environment appear in the manifest. Verify the native version and executable SHA-256 before dispatch. Only
`ANTHROPIC_API_KEY` is forwarded, by environment-variable name; the endpoint is `https://api.anthropic.com`. Missing
credentials or a version mismatch aborts without inference. No login or gateway fallback is authorized.

The fixed parent prompt requests one custom subagent, whose only permitted task is a fixed acknowledgement. Both use
`claude-haiku-4-5-20251001` (the subagent's `haiku` selection must be checked in the resulting metadata). Parent tools
are limited to the agent tool names used across the pinned CLI family; the custom child has no tools. There is no
repository context, file-reading task, resume or retry. An unavailable agent tool is a failed observation, not
permission to broaden tools or rerun.

The single invocation has a 90-second outer deadline, two parent agentic turns, one requested child and 512 output
tokens per completion. `--max-budget-usd 0.10` provides the native CLI spending limit. This is a **$0.10 planning
allowance**, not an invoice guarantee: retries within the native client and provider accounting are not controlled by
the outer harness. No further invocation is approved by this proposal. Export the returned cost and usage if available;
missing accounting is recorded as unknown and cannot trigger another call.

Capture the runtime census while the process is live and after it exits. Keep the exact generated transcript and agent
paths, header identity fields and SHA-256 fingerprints; do not export credentials or unrelated files. Verify byte
preservation through delete and exact-path removal through purge using only this disposable store. Construct relocation
and rewind copies offline from the generated source; preserve an unrelated sentinel and assert its bytes remain equal.
Export evidence before removing only this exact container. This run exported its evidence and removed its container, as
specified by the approved manifest's cleanup field.

## Limits that remain explicit

Process enumeration observes same-runtime native clients, including clients outside Forge. It cannot lock an external
runtime against starting after the last check. Purge repeats the census and file identity check before unlink; unknown
process visibility refuses. The implementation makes no stronger exclusion claim.

The inventory covers recorded original/rollover files, verified relocation/rewind copies, verified agent logs and exact
Codex rollouts. Provider copies, project memory edits, Git history, telemetry, Claude history/file-history and native
indexes are outside removal scope. Unknown Codex archived ancestry refuses because those descendants may require a live
parent. Arbitrary copies in unrecorded locations cannot be inventoried completely.
